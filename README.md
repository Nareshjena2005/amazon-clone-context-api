# Amazon Clone – React E-commerce App

A React-based Amazon-inspired e-commerce application built to practice frontend development, API integration, and global state management using Context API.

## 🚀 About the Project

This project is an Amazon-inspired shopping application where users can browse products, search for products, and interact with a shopping cart.

The main goal is to build a practical e-commerce application while learning React concepts and state management.

## ✨ Features

- Product listing using API integration
- Product images, titles, and prices
- Search and filter products
- Responsive product layout
- Shopping cart using React Context API (in progress)
- Add products to cart
- Cart page to display selected products

## 🛠️ Technologies Used

- React.js
- JavaScript
- Tailwind CSS
- React Router
- Context API
- Redux Toolkit
- React Toastify
- API Integration

## 📂 Project Setup

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate to the project folder:

```bash
cd amazon-clone-context-api
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
